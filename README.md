# タイマークイズゲーム

## 概要
制限時間内に問題を解くシンプルなクイズゲームです。不正解するとペナルティとして時間が減少します。

## 特徴
- 残り時間のカウントダウンタイマー
- 複数のステージ構成
- 段階的なヒントシステム
- 不正解時のペナルティタイム
- 効果音（正解、不正解、タイムアップ、警告）
- ゲーム状態の自動保存機能

## 遊び方
1. スタート画面で「スタート」ボタンをクリックしてゲームを開始
2. 表示される問題に対して答えを入力
3. 「送信」ボタンで答えを確定
4. 正解すると次のステージへ進む
5. 不正解するとペナルティとして時間が減少
6. 「ヒントを見る」をクリックするとヒントが表示される
7. すべてのステージをクリアするか、制限時間が0になるとゲーム終了

## ゲームの設定
ゲームの設定は `game-data.js` ファイルで変更できます。

### タイマー設定
```javascript
const GAME_CONFIG = {
  // ゲーム時間（秒）
  TIME_LIMIT: 65,
  // 不正解時のペナルティ（秒）
  PENALTY_TIME: 30
};
```

### 問題追加
新しい問題を追加するには、`GAME_QUESTIONS` 配列に問題オブジェクトを追加します。

```javascript
{
  stage: 4, // ステージ番号
  text: "問題文をここに入力",
  image: "assets/images/image.jpg", // 画像パス（なければ空文字）
  answers: ["答え1", "答え2"], // 正解となる答えの配列
  hints: [ // ヒントの配列
    "1つ目のヒント",
    "2つ目のヒント",
    "3つ目のヒント"
  ]
}
```

## 技術情報
- HTML5, CSS3, JavaScript (ES6)
- ipadを使う想定でデザインしています。
- リロードしても状態を保持するため、進行状況をローカルストレージに保持しています。
- ゲームオーバー or ゲームクリア後に最初の画面に戻ることでローカルストレージに保存された進行状況をリセットします。

## インストール方法
1. リポジトリをクローンまたはダウンロード
2. `index.html` をウェブブラウザで開く

## ファイル構成
- `index.html` - メインのHTMLファイル
- `style.css` - スタイルシート
- `script.js` - ゲームロジック
- `game-data.js` - ゲーム設定とクイズデータ
- `assets/` - 画像、音声などのリソースディレクトリ
